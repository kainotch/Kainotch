# KaiNotch

Source code for the personal website, portfolio, and digital garden of KaiNotch.

- **Live URL**: [kainotch.vercel.app](https://kainotch.vercel.app)
- **Author**: KaiNotch ([@KaiNotch](https://github.com/KaiNotch))

---

## Overview

A fast, static website built with modern web standards, featuring:

- **Astro Static Engine**: Minimal JavaScript footprint, fast initial page loads, and zero framework overhead.
- **Interactive ASCII Matrix**: Dynamic background canvas inspired by terminal aesthetics.
- **Responsive Layout**: Desktop sticky sidebar with video backdrop, custom Pokémon GameBoy volume controls, and clean mobile viewports.
- **GitHub Contribution Bento**: Auto-updating contribution heatmap card highlighting recent activity.
- **Writing & Projects**: Blog posts with RSS feed support and detailed application showcases for [Wammy](https://github.com/kainotch/Wammy) and [Neru](https://github.com/kainotch/Neru).
- **Zero Emojis**: Clean, intentional typography set with Outfit Variable and Google Sans Code Variable.

---

## Tech Stack

- **Framework**: [Astro](https://astro.build)
- **Language**: TypeScript / JavaScript
- **Styling**: Pure CSS with CSS custom properties and theme switching
- **Deployment**: [Vercel](https://vercel.com)

## Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/kainotch/Kainotch.git
cd Kainotch

# Install dependencies
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

### Production Build

Create an optimized static build in the `dist/` directory:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
